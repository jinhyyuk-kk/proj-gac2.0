# CHANGE-002 implementation plan

Spec: `docs/changes/CHANGE-002.md` (moved from the repo root when done).

1. **Icons** — `tools/Gac.IconTool` (`extract`, `build`), commit the four assets under `assets/icons`, wire
   `<ApplicationIcon>`, window icons, tray `NotifyIcon`, Console logo, Inno `SetupIconFile`/`UninstallDisplayIcon`.
   New test project `tests/Gac.Icons.Tests` (extract round-trip through `UpdateResource`, build from a non-square
   transparent PNG, assets parse, every exe embeds the right icon, iss files point at the right icon).
2. **Lock exemption days** — Shared: `ExemptionDay` + recurrence expansion (`ExemptionCalendar`), `TrustedClock`
   (server time + monotonic offset, 10-minute tamper rule, Asia/Seoul day). Server: `exemption_days` table,
   `ExemptionService`, endpoints, poll response carries server time + next-60-day dates. Agent: persisted list +
   clock, `LockController` suppresses `lock_pc` and clears an open lock on an exemption day. Tray: closing the last
   lock restarts `explorer.exe`. Permission `ManageCalendar`. Console 캘린더 screen.
3. **Server install firewall step** — `install` no longer opens the firewall; new `firewall --port --range` verb creates
   the rule and reads it back; `server.json` records `InstallComplete`. Until then the service refuses enrollment,
   agent traffic and sign-up (503) and the setup code is hidden. Inno: post-install custom pages
   (방화벽 열기 → 설치 완료) with Cancel/Back hidden.
4. **GAC 서버 관리** — rebuild `Gac.ServerStatus` with a left menu (상태 / 자동 종료 / 과부하 차단 / 로그) + tray icon.
   Server: `ServerShutdownService` (weekday schedule, exception dates, T−10 warning, skip-today, +30 min, waits for
   running deploy/update jobs ≤ 30 min, missed runs skipped), `OverloadGuard` middleware (per-agent/per-source limits,
   doubling blocks, 429, alerts queued for the Console). Permissions `ManageServerShutdown` (Owner+Admin) and the
   existing `ManageServerSettings` for limits. Console 알림 and 서버 관리 screens.
5. **Demo** — icons, 캘린더/알림 samples, installer firewall pages, fake GAC 서버 관리, exemption-day toggle on the client.
6. **Docs** — CLAUDE.md sync, DECISIONS, PROGRESS, archive the spec.
