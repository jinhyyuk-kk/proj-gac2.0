# GAC 2.0 설치 안내

GAC 2.0은 **무료(0원)** 학교 PC 관리 프로그램입니다. 라이선스 키, 사용 기간, PC 대수 제한이 없습니다.
모든 구성 요소는 **학교 내부 네트워크(LAN)에서만** 동작하며 인터넷에 연결하지 않습니다.

## 0. 먼저 체험해 보기 – `GAC-Demo.exe`

- 설치 없이 더블클릭하면 실행됩니다 (USB에서도 가능, 관리자 권한 불필요).
- 가상의 학교(PC 약 20대)로 콘솔 화면과 9개 기능을 모두 체험할 수 있습니다.
- **실제 PC에는 아무 변화도 없습니다.** 파일 삭제, 종료, 레지스트리, 서비스, 프로그램 실행, 네트워크 연결을 하지 않으며, 창을 닫으면 모든 내용이 사라집니다.
- 메뉴 `보기 → 선생님용 트레이 미리 보기`에서 수업 모드 프리셋 편집기와 네트워크 자가 진단을 체험할 수 있습니다.

## 1. 구성

| 설치 파일 | 설치 위치 | 역할 |
| --- | --- | --- |
| `GAC-Server-Setup.exe` | 관리 PC 1대 (일반 Windows 10/11 PC) | PC 목록·명령·기록 저장, 배포 파일 보관 |
| `GAC-Console-Setup.exe` | 관리자가 쓰는 PC | 관리 화면 |
| `GAC-Agent-Setup.exe` | 관리할 모든 학교 PC | 에이전트 서비스 + 선생님용 트레이 앱 |

서버 PC는 서버용 하드웨어나 Windows Server, 도메인(AD), WSUS, IIS, SQL Server가 **필요 없습니다.**
관리 PC가 꺼져 있어도 각 PC의 자동 정리·자동 종료는 그대로 실행되고, 결과는 나중에 서버로 보내집니다.

## 2. 설치 순서

### ① 관리 PC에 서버 설치
1. `GAC-Server-Setup.exe`를 실행합니다 (관리자 권한).
2. 마지막 화면에 **서버 주소**와 **등록 코드**가 표시됩니다. 적어 두세요.
   같은 내용이 `C:\ProgramData\GAC\Server\enrollment.txt`에도 저장됩니다 (관리자만 읽을 수 있음).
3. 설치 프로그램이 관리 PC의 방화벽에서 **TCP 8443 포트 1개만** 엽니다 (도메인·개인 네트워크 프로필).
   학생 PC에는 열리는 포트가 없습니다.

다른 포트를 쓰려면: `GAC-Server-Setup.exe /PORT=9443`

### ② 콘솔 설치와 첫 로그인
1. `GAC-Console-Setup.exe`를 설치하고 실행합니다.
2. 서버 주소와 등록 코드를 입력합니다. 콘솔은 등록 코드로 서버를 확인한 뒤 서버 인증서를 고정합니다.
3. 처음에는 **최고 관리자 계정 만들기** 화면이 나옵니다. 기본 비밀번호는 없습니다.
   이때도 등록 코드가 필요합니다 (다른 사람이 먼저 최고 관리자를 만드는 것을 막기 위함).
4. `관리 → 계정 관리`에서 관리자·운영자·조회 전용 계정을 추가합니다.

### ③ 학교 PC에 에이전트 설치

화면에서 설치할 때는 설치 중에 서버 주소와 등록 코드를 입력합니다.

여러 대에 한꺼번에 설치(무인 설치):

```bat
GAC-Agent-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /SERVER=ADMIN-PC:8443 /CODE=K7QM-2XPA-9RTD
```

설치가 끝나면 PC가 콘솔의 `PC 목록`에 나타납니다. 왼쪽 그룹 목록과 `그룹 이동`으로 반·교실별로 정리하세요.

## 3. 처음 운영 시 권장 사항

- **자동 정리는 처음에 '미리 보기'로만 동작합니다.** `보고서 → 자동 정리`에서 지울 대상이 예상과 맞는지 확인한 뒤
  `관리 → 그룹별 정책 → 자동 정리`에서 '미리 보기만'을 끄세요.
- 자동 종료 시각은 그룹마다 `관리 → 그룹별 정책 → 자동 종료`에서 정합니다. 종료 5분 전 경고 창에 '30분 연장'과 '지금 종료' 버튼이 나옵니다.
- GAC는 Windows 업데이트 후 **자동으로 재부팅하지 않습니다.** 재부팅이 필요한 PC는 PC 목록에 표시됩니다.

## 4. Windows SmartScreen 경고

GAC 설치 파일은 코드 서명이 되어 있지 않아 처음 실행할 때 "Windows의 PC 보호" 창이 나올 수 있습니다.
**추가 정보 → 실행**을 누르면 설치가 계속됩니다. 학교 보안 프로그램이 차단하면 아래 6절을 참고해 예외로 등록하세요.

## 5. 업그레이드와 제거

- **업그레이드:** 새 설치 파일을 그대로 실행하면 그 자리에서 업그레이드되며 설정과 데이터는 유지됩니다.
  에이전트는 등록 정보를 유지하므로 서버 주소와 코드를 다시 입력하지 않아도 됩니다.
- **제거:** `설정 → 앱`에서 제거합니다. 서비스, 방화벽 규칙, 프로그램 파일이 모두 삭제됩니다.
  - 서버: 데이터베이스는 기본적으로 남겨 둡니다. 함께 지우려면 제거 창에서 **'데이터도 삭제'**를 선택하세요
    (무인 제거: `unins000.exe /VERYSILENT /DELETEDATA=1`).
  - 에이전트: `C:\ProgramData\GAC\Agent`(등록 정보, 대기 중인 결과, 로그)까지 삭제합니다.
  - 선생님이 만든 개인 프리셋(`%APPDATA%\GAC\presets.json`)은 각 사용자의 데이터이므로 남겨 둡니다.

## 6. 보안 프로그램 예외 등록용 동작 설명

| 프로그램 | 실행 계정 | 하는 일 |
| --- | --- | --- |
| `Gac.Server.exe` (서비스 `GACServer`) | LocalSystem | TCP 8443(HTTPS)으로 콘솔과 에이전트의 요청만 받음. 데이터: `C:\ProgramData\GAC\Server` |
| `Gac.Agent.exe` (서비스 `GACAgent`) | LocalSystem | 관리 PC로 **나가는** 연결만 함 (들어오는 포트 없음). 서명된 명령만 실행. 데이터·로그: `C:\ProgramData\GAC\Agent` |
| `Gac.Tray.exe` | 로그인한 사용자 | 알림 영역 아이콘. 수업 모드 프리셋을 사용자 권한으로 실행. 서비스와는 이름 있는 파이프 `GAC.Agent.Tray.v1`로만 통신 |
| `Gac.Console.exe` | 관리자 | 관리 화면. 관리 PC로 HTTPS 연결 |

에이전트가 삭제하는 파일은 Windows 임시 폴더, 사용자 임시 폴더, Chrome/Edge 캐시(브라우저가 실행 중이 아닐 때),
휴지통, 다운로드 폴더의 오래된 파일(기본 14일)뿐입니다. 바로 가기 링크(정션/심볼릭 링크)는 따라가지 않습니다.
모든 통신은 설치 때 만든 자체 서명 인증서로 암호화되며, 각 PC는 등록할 때 그 인증서를 고정합니다.
